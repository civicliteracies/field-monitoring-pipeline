# ADR-0023 — One advisory Linux run, not required to merge [decision]
**Status:** Accepted (2026-08-31). **Owner:** CLI.
**Context.** [ADR-0021](0021-every-check-runs-on-the-maintainers-machine.md) removed every GitHub workflow, on the reasoning that checks on a build server earn their place when you cannot control whether contributors run them locally, which is not this project's situation. That reasoning holds for every check except one thing a local gate structurally cannot see: an operating system it does not run on. The build machine is Windows and the scheduled run executes on Linux. That gap has already produced two faults during this build. The first was the line endings that made `.gitattributes` necessary. The second happened while writing this decision: a shell script was rewritten with Windows line endings and could not execute, and only a manual run caught it. [ADR-0020](0020-ci-runs-the-gate-and-reports.md) had kept exactly this advisory run before ADR-0021 removed it.
**Decision.** One workflow, running `mise run verify` on Ubuntu for every pull request. It is advisory: no status check is required to merge, so a red tick is a reason to look rather than a block. It runs the same task the pre-push hook runs and nothing else. Nothing removed by [ADR-0022](0022-the-gate-is-the-four-standard-checks.md) returns with it, and the ruleset is unchanged.
**Consequences.** The one class of fault a local gate cannot catch is now caught, on a public repository where Actions minutes are unlimited and no key is involved. Enforcement stays in the pre-push hook, so nothing changes about what may merge. The cost is one more file and one more moving part, which the boring-technology rule counts against; the judgement is that a whole class of platform fault is worth one file that runs one command. **This departs from CLI's stated position that every check belongs on the maintainer's machine.** The departure is deliberate, made by a member of CLI, and recorded here so it stays visible rather than becoming quiet drift. Supersedes the part of ADR-0021 that removed GitHub Actions entirely.
