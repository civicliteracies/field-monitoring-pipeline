# ADR-0020 — CI runs the gate and reports; nothing is required to merge [decision]
**Status:** Accepted (2026-08-31). **Owner:** build, following CLI's position on the required check.
**Context.** [ADR-0019](0019-quality-gate-runs-in-the-push-hook.md) left two things open: whether CI runs at all, and whether it becomes a required status check. CLI's position is that a required check is redundant at this team size, because the whole gate now runs in the pre-push hook and the team agrees to run it, and that an unreviewed self-merge is a matter of team agreement rather than repository risk. Removing the workflow altogether was considered and rejected: `ci.yml` also carries the documentation guard, which works by comparing the files changed in a pull request and therefore cannot run in a local hook at all, plus the dependency audit and the frozen-lockfile check. `AGENTS.md` already states that CI enforces the documentation rule.
**Decision.** `ci.yml` keeps running on every pull request and push, and nothing about it is required to merge. It runs `verify` rather than `check`, so it cannot report green on code it silently repaired. The ruleset stays exactly as configured: a pull request required for every change to `main`, no force-push, no deletion, an empty bypass list, no required status check, and no required approval.
**Consequences.** PR 1's goal changes from making the gate enforce on GitHub to making it report there, with enforcement in the pre-push hook. That is a departure from the original plan and is recorded so it stays visible rather than becoming quiet drift. The documentation guard, the dependency audit, and the lockfile check survive, and they are the reason the workflow stays. CI runs on Linux while the build machine is Windows, so a platform difference is still caught, which is not redundant: the line-endings fault that made `.gitattributes` necessary was exactly that. A red check is advisory, so someone can merge over it; the team agreeing not to is the control, and that is a deliberate trade rather than an oversight. Closes the question left open in ADR-0019.
