# ADR-0034 — The text the model reads is derived, and the deterministic side carries its own version [decision]
**Status:** Accepted (2026-09-03). **Owner:** CLI.
**Context.** A captured item is rarely plain words. A feed entry carries markup inside it, roughly a quarter of one measured entry, and a page carries a great deal more. Measurement on two real funder pages showed what that costs: two of five candidate quotes were not substrings of the bytes the server sent, while all five were substrings once markup was removed, and the two that failed were the deadline and the eligibility, because each carried a tag or an escaped character in the middle of the words. So a quote check against the raw bytes refuses honest quotes on the field the check exists for. This is not a property of one page. It follows from the fact that a sentence a person reads is one run of words and a sentence in a source is not. Once a derivation exists, a second question follows: a stored quote is checked again on every push and again on rebuild, against text derived from the archive by that same code, so the derivation becomes part of what a record means.
**Decision.** One derivation turns a captured item into a single readable string, and that same string is both what the model reads and what every quote is checked against. It uses the standard library only: markup removed, character references decoded, script and style content dropped, block boundaries turned into line breaks, and invisible characters settled. A page's declared furniture is dropped as well, because a menu on a funder's site lists that funder's other programmes and a sentence from one of those is a real substring of this page and would pass the check while describing a different grant. Headers are kept, since one of the two test pages puts its own heading inside one, and measurement showed dropping them loses the title. Comparison composes characters rather than converting them: the compatibility form rewrites a superscript five into a plain five, which would silently change a figure in a system whose job is reading budgets. Collapsing whitespace already handles the unusual spaces that form is otherwise reached for. And the deterministic side carries its own version, stored on every record beside the prompt version and the model name, so a value is attributable to the exact logic that produced it.
**Consequences.** The quote check becomes sound, because the model and the checker read the same string. Nothing is added to the dependency list, which was measured before it was claimed. The derivation is versioned rather than frozen, which is the choice that keeps it fixable: freezing would make a parser that meets an unhandled date format unrepairable, and it would contradict the rebuild slice, which re-derives every record under current logic. A change to it that alters behaviour therefore earns a decision record and a rebuild, and a stored record names the version it was built under. The archive and the frozen fixtures are also excluded from line ending normalisation in `.gitattributes`, without which a quote spanning a line break verifies on the machine that captured it and fails on every other machine. Two costs are accepted. A page's furniture is judged by the tags a page declares, so a site that declares none keeps its menus, and the known limit is recorded rather than hidden. And the derivation is one more piece of this project's own code where a library could have been used, which was measured and preferred because every library considered would have been a new dependency for a job the standard library already does on both test pages.
