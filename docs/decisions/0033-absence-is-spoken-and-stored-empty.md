# ADR-0033 — Absence is spoken out loud by the model and stored as an empty field [decision]
**Status:** Accepted (2026-09-03). **Owner:** CLI.
**Context.** Two rules appeared to disagree. One said anything absent is the first-class value "not stated", never invented. The other, written into the record shape itself, said an absent field is simply empty. Reading them as a conflict was a mistake: they describe two different moments. The first is about what the model must say, and exists so a model is never under pressure to invent a value it cannot find. The second is about what a card holds, and a field that is a value paired with a quote has neither when the page says nothing. The shape also already answers a question that was being asked separately, which is which fields may be absent at all: four are marked as able to be empty and four are not, and that marking is the whole list.
**Decision.** The model states an absence out loud, using a flag of its own for each field that may be absent, and the record stores an empty field. Funder, budget, eligibility and area may be absent. Title, type, timing and summary may not, so a summary can never be answered as not stated and a card always has something on it. Leaving a field out of the command entirely is refused as a malformed answer rather than read as an absence, because only one of those two is honest and a model that quietly drops a field would otherwise go unnoticed. No separate stored marker distinguishes "the page does not say" from "the model could not tell". The second cannot be verified by any check this system can run, and a state the code cannot check is machinery this project does not build.
**Consequences.** The rule that a model is never pressured to invent becomes true rather than hoped for, because saying nothing about a field is an error the model is asked to correct. The record shape does not change. A reader of a card sees an empty field, and the slice that renders cards decides whether to print a line saying so. The cost is one flag per optional field in the command, and a model that forgets one gets a second attempt rather than a silent gap.
